Publishing with GitHub Pages:
1. Create a folder named docs in the root of the Homesick repository.
2. Copy all website files into docs.
3. Run:
   git add docs
   git commit -m "Add Homesick legal website"
   git push
4. On GitHub: Settings > Pages
5. Source: Deploy from a branch
6. Branch: main
7. Folder: /docs
8. Save.

Important:
Google Play requires both an in-app account-deletion path and a public web resource.
This package provides the web resource. Confirm the app also has a working
Settings > Account > Delete account function before release.
